## PING PONG  
The Simple 2D Ping Pong Games made using unity Game Engine.  

# How it's works: 
This Game Has Three Scenes Main Menu, Game Scenes and Aiplay Scenes. The Main Menu Scenes contain a good UI with background image and three buttons of 1V1, VS AI and Exit. In Game Scenes and AIplay Scenes there are a good UI with the score of Player. In this game there is background sound and ball sound when it collided with any wall or paddle it play ball sound. When ball goes out of Scene the score increase. When we play continuously without getting out then the ball speed increasing

## Features 
- Player vs Player
- Player vs Ai
- Pause Button
- Home Button
- Restart Button
- Continue Button
- Win screen
- Ai paddle System which follow the y axis of ball
- Background Sound
- Ball Collided Sound

## Controls
### Blue Paddle
- w for up
- s for down
### Yellow Paddle
- Up Arrow for up
- Down Arrow for down
